<h1>Calculator App</h1>
<p>This is a modern-looking and user-friendly calculator application developed using Swift and UIKit.</p>

<h2>🚀 Features</h2>
<ul>
    <li><strong>Basic Operations:</strong> Addition, subtraction, multiplication, and division functions.</li>
    <li><strong>Advanced Options:</strong> Support for changing the number sign (+/-) and calculating percentages (%).</li>
    <li><strong>Precise Display:</strong> A clean interface that removes unnecessary decimal places with the %g formatter.</li>
</ul>

<h2>🛠 Technical Details</h2>
<ul>
    <li><strong>Language:</strong> Swift</li>
    <li><strong>Framework:</strong> UIKit (Storyboard & Auto Layout)</li>
    <li><strong>Architecture:</strong> Event-driven logic.</li>
</ul>
