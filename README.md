Calculator App

This is a modern-looking and user-friendly calculator application developed using Swift and UIKit.

🚀 Features
Basic Operations: Addition, subtraction, multiplication, and division functions.

Advanced Options: Support for changing the number sign (+/-) and calculating percentages (%).

Precise Display: A clean interface that removes unnecessary decimal places with the %g formatter.

🛠 Technical Details
Language: Swift

Framework: UIKit (Storyboard & Auto Layout)

Architecture: Event-driven logic.
